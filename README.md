# ✈️ FlightRemind

**FlightRemind** — Telegram-бот, который помогает пользователю не забыть важные этапы перелёта в день поездки.  
Бот получает актуальные данные о рейсе через авиационный API и автоматически отправляет напоминания прямо в Telegram.

Проект разработан в учебных целях и демонстрирует работу со сторонним API, обработку данных и создание прикладного Telegram-бота.

## 🎯 Идея проекта

Пользователи часто проверяют статус рейса вручную и могут пропустить регистрацию, выход к гейту или посадку.  
**FlightRemind** решает эту проблему, автоматически предоставляя информацию о рейсе и напоминая о ключевых моментах перелёта.

---

## 🚀 Возможности

- Пошаговый ввод данных:  
  **номер рейса → дата**
- Получение актуальной информации о рейсе:
  - статус рейса
  - аэропорты вылета и прилёта
  - плановое и ожидаемое время
  - терминал и гейт (если доступны)
  - тип самолёта
- Обновление информации одной кнопкой
- Работа полностью внутри Telegram

---

## 🧩 Используемые технологии

- **Python 3.10+**
- **aiogram 3** — Telegram Bot API
- **FlightAware AeroAPI** — получение данных о рейсах
- **APScheduler** — планирование напоминаний
- **requests** — HTTP-запросы
- **python-dotenv** — работа с переменными окружения

---

## 🔗 Используемые API (открытый доступ)

- **Telegram Bot API**  
  https://core.telegram.org/bots/api

## ⚙️ Установка и запуск

### 1️⃣ Клонировать репозиторий
```bash
git clone https://github.com/aarakcheev-24/FlightRemind.git
cd FlightRemind
```
### 2️⃣ Создать виртуальное окружение
```bash
python3 -m venv .venv
source .venv/bin/activate
```
### 3️⃣ Установить зависимости
```bash
pip install -r requirements.txt
```
### 4️⃣ Настроить переменные окружения

Создать файл .env:
```bash
touch .env
```
Заполнить .env:
```bash
nano .env

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
AEROAPI_KEY=YOUR_FLIGHTAWARE_API_KEY
```
### 5️⃣ Запустить бота
```bash
python3 main.py
```
